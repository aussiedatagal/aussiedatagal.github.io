## Adding a project

The project list updates itself every day. To add a project, give its repo the `portfolio` topic on GitHub (it needs GitHub Pages turned on). New projects appear at the top with a screenshot taken automatically. To change the order or the wording on a card, edit `data/portfolio.json`. Remove the topic to take a project off the page.
